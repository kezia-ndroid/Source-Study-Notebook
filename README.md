# Source Study Notebook

Source Study Notebook is a study tool designed to help students turn their study notes into flashcards and quiz questions.

## Features

- Generate flashcards and quiz questions from study notes.
- Review generated cards before adding them to your library.
- Approve, edit, or discard generated cards.
- Save approved cards in a searchable study library.
- Practice with saved cards to revise concepts and improve learning.

## Purpose

The goal of Source Study Notebook is to make studying easier by helping students organize learning materials, create revision questions, and practice what they have learned.

## Built With

This project is developed using Replit.
